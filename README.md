# 🏡 Indian House Price Prediction App

This is a simple yet powerful web application built using **Streamlit** that predicts the price of a house in India based on user-input features. It leverages a **Machine Learning model** to give accurate price estimates.

---

## 🚀 Features

- Predict house prices based on:
  - 🛏️ Number of Bedrooms
  - 🛁 Number of Bathrooms
  - 📏 Living Area (in sqft)
  - 🏠 House Condition (scale 0–5)
  - 🏫 Number of Nearby Schools
- Simple and intuitive user interface
- Real-time predictions
- Beautiful, customized layout
